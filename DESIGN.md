# Smart Bell interface

Extend the incumbent teal and mint interface into a practical control application. Use familiar system typography, clear dark ink on warm light surfaces or pale text on deep teal surfaces. Support light, dark and system appearance. Desktop navigation is a left rail; mobile navigation stays reachable without a long document.

Five views: Live view, Activity, Cards, Settings, Diagnostics. Keep urgent alarm status and connection state visible. The entrance video is the main workspace, with bounded controls alongside. Recent activity is a short preview; full history is searchable and paginated. Use normal labeled forms, explicit save actions and device confirmation. Never imply a relay pulse proves the gate physically moved.
